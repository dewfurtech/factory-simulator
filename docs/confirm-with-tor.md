# ข้อมูลที่ต้องให้พี่ต่อยืนยันก่อนส่งลูกค้า

ข้อมูลในตารางนี้เดามาจากโมเดลหรือรูปถ่าย ยังไม่มีใครยืนยัน ลูกค้าจะเห็นทั้งหมดในแอป
ถ้าข้อไหนผิด แก้ได้ที่ `src/machines/data.js` บรรทัดละหนึ่งจุด

(สร้างเมื่อ 23 ต.ค. 2026)

ทิศนับจากการยืนหน้าเครื่อง คือด้านที่มีขีดหนาบนผัง

| Booster e6 / e7 / e10 | ขวา | ซ้าย | รางลูกกลิ้งฝั่งป้อนในโมเดล | ควรยืนยัน |

## 2. รูปเครื่องจริง

| รุ่น | รูปที่แสดง |
| --- | --- |
| Moon 10 | ใช้รูป Moon 40 (มีข้อความบอกใต้รูป) |
| Moon 40d | ใช้รูป Moon 40 (มีข้อความบอกใต้รูป) |
| Stella, Smooth Flat, Smooth 60, Becker VTLF | ไม่มีรูปและไม่มีโมเดล จึงไม่อยู่ในคลัง |

ถ้ามีรูปจริงของ Moon 10 กับ Moon 40d ให้ใส่ในโปรเจกต์ Model (`photos/<id>/`) แล้วรัน `node scripts/photos.mjs` ตาม README

## 3. ขนาดเครื่องที่ไม่ได้มาจากโบรชัวร์

| รุ่น | ขนาดที่ใช้ |
| --- | --- |
| Nebula | โบรชัวร์ไม่มีขนาดรวม แอปใช้ขนาดที่วัดจากโมเดล 3D (3,200 × 3,475 × 1,300 มม.) และในแผงบอกว่า "วัดจากแบบเครื่อง" |
| Rakete 3500A + โต๊ะยก/สายพาน | ขนาดรวมวัดจากโมเดล ไม่มีในโบรชัวร์ |
| ทุกรุ่นบนผัง | พื้นที่ที่กันไว้บนผังคือขนาดของโมเดล รวมส่วนยื่น เช่น จอ แขน ตู้คอนโทรล จึงอาจใหญ่กว่าตัวเลขในโบรชัวร์ |

## 4. อุปกรณ์เสริมของ Rakete 3500A

ชื่อและคำอธิบายของโต๊ะยกไม้ สายพานลำเลียงออก และชุดดูดแผ่นป้อนอัตโนมัติ ตั้งขึ้นเองจากโมเดล ไม่มีราคาเพราะยังไม่มีในรายการราคา
