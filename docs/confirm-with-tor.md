# ข้อมูลที่ต้องให้พี่ต่อยืนยันก่อนส่งลูกค้า

ข้อมูลในตารางนี้เดามาจากโมเดลหรือรูปถ่าย ยังไม่มีใครยืนยัน ลูกค้าจะเห็นทั้งหมดในแอป
ถ้าข้อไหนผิด แก้ได้ที่ `src/machines/data.js` บรรทัดละหนึ่งจุด

(สร้างเมื่อ 23 ต.ค. 2026)

ทิศนับจากการยืนหน้าเครื่อง คือด้านที่มีขีดหนาบนผัง

## 3. ขนาดเครื่องที่ไม่ได้มาจากโบรชัวร์

| รุ่น | ขนาดที่ใช้ |
| --- | --- |
| Nebula | โบรชัวร์ไม่มีขนาดรวม แอปใช้ขนาดที่วัดจากโมเดล 3D (3,200 × 3,475 × 1,300 มม.) และในแผงบอกว่า "วัดจากแบบเครื่อง" |
| Rakete 3500A + โต๊ะยก/สายพาน | ขนาดรวมวัดจากโมเดล ไม่มีในโบรชัวร์ |
| ทุกรุ่นบนผัง | พื้นที่ที่กันไว้บนผังคือขนาดของโมเดล รวมส่วนยื่น เช่น จอ แขน ตู้คอนโทรล จึงอาจใหญ่กว่าตัวเลขในโบรชัวร์ |

## 4. อุปกรณ์เสริมของ Rakete 3500A

ชื่อและคำอธิบายของโต๊ะยกไม้ สายพานลำเลียงออก และชุดดูดแผ่นป้อนอัตโนมัติ ตั้งขึ้นเองจากโมเดล ไม่มีราคาเพราะยังไม่มีในรายการราคา

## 5. ค่าประมาณในแผง "ที่ปรึกษาผัง" (เพิ่ม 30 ต.ค. 2026)

ตัวเลขเหล่านี้ใช้คิดคะแนนผัง สรุปการเตรียมหน้างาน และตัวช่วยเริ่มต้น ยังไม่มีใครยืนยัน ลูกค้าเห็นในแอปพร้อมคำว่า "ค่าประมาณ"

| เรื่อง | ค่าที่ใช้ | แก้ที่ |
| --- | --- | --- |
| กำลังไฟ Moon 10 / 40 / 40d (โบรชัวร์ไม่มี) | 18 / 22 / 28 kW | `POWER_GUESS` ใน `src/model/sitePrep.ts` |
| ลมอัดที่ใช้ (ลิตร/นาที) | CNC 300, Booster 200, Moon 350, Nova 150, Aurora 150 | `AIR_BY_CAT`, `AIR_BY_ID` ไฟล์เดียวกัน |
| ลมดูดฝุ่น (ลบ.ม./ชม.) | CNC 3,500, Booster 1,800, Moon 2,000–2,500, Nova 1,200, Nebula 1,500 | `DUST_BY_CAT`, `DUST_BY_ID` ไฟล์เดียวกัน |
| แผ่นที่ตัดได้ต่อวัน (8 ชม.) | 3500A 30, 3500Ant 45, 4800Ant 55, 5000AF 70 | `SHEETS_PER_DAY` ใน `src/model/starter.ts` |
| ชุดเครื่องที่แนะนำตามคำตอบ | ดูฟังก์ชัน `recommend` | `src/model/starter.ts` |
| ลังเครื่องตอนขนส่ง | ขนาดเครื่อง (ไม่รวมอุปกรณ์เสริม) + ข้างละ 10 ซม. สูงเพิ่ม 15 ซม. บนรถยก ไลน์ Ant นับเป็นลังเดียวยาว 10 ม. | `src/model/delivery.ts` |
| ลำดับงาน | เลื่อย/CNC → ปิดขอบ → เจาะ → ทากาว/เมมเบรน → อัดเย็น | `STAGE_BY_*` ใน `src/model/route.ts` |

**ควรถาม:** ไลน์ Rakete Ant ส่งเป็นลังเดียวหรือแยกส่วน (ถ้าแยก ทางขนเข้าจะผ่านง่ายกว่าที่แอปบอก)
