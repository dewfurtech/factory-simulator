## ที่มา

พี่ต่อไม่รับโมเดล 3D ที่ "ดูไม่เหมือนเครื่องจริง" แต่รับ "ก้อน ๆ สีเทา ขนาดถูกต้อง กดดูรูปถ่ายได้"
กล่องเทาเปล่า ๆ ดูแย่เกินไป จึงทำทางกลาง: เอาโมเดลจริงมา **แปลงเป็นก้อนเหลี่ยม** ที่ยังดูออกว่าเป็นรุ่นอะไร

## วิธีที่ทำใน Factory Simulator (`src/view3d/machines3d.ts`)

1. สร้างโมเดลจริงจาก `MODELS[id](flags)` ใน `src/machines/registry.js` (ไฟล์ชุดเดียวกับโปรเจกต์ Model)
2. ตัด workpiece และแผ่นเหลืองจุดยืน (`userData.operatorZone`) ออก
3. ไล่ทุก mesh ที่มองเห็น แล้ว **เปลี่ยนแต่ละชิ้นเป็นกล่องเท่ากับ bounding box ของชิ้นนั้น** (ในเฟรมของชิ้นเอง จึงยังเอียงตามชิ้นได้) สีเดียวกับวัสดุเดิม
   - ชิ้นที่เส้นทแยง bounding box สั้นกว่า `MIN_PART = 0.12 ม.` ตัดทิ้ง (น็อต ปุ่ม ป้าย ไฟเล็ก)
   - `TubeGeometry` รัศมีต่ำกว่า `MIN_TUBE = 0.035 ม.` ตัดทิ้ง (สายลม สายไฟ)
   - แผ่น `PlaneGeometry` ที่มี texture (ข้อความ โลโก้) ตัดทิ้ง
   - วัสดุที่มี texture ใช้สีเทา `#b4b8bd`; วัสดุโปร่งใส (ฝาอะคริลิก) ทำทึบแล้วผสมขาว 45 %; emissive บวกเข้าสีเล็กน้อย
   - `InstancedMesh` แตกเป็นกล่องต่ออินสแตนซ์
4. รวมทุกกล่องเป็น geometry เดียว (vertex color, flat shading, ไม่มีเงา) เลื่อนให้กึ่งกลางฐานอยู่ที่ origin ด้วย `center` จาก `src/machines/sizes.json`
5. cache ต่อ `รุ่น|ตัวเลือกเสริม` แล้ววางหลายเครื่องด้วย geometry ร่วมกัน ย่อ/ขยายให้พอดีขนาดที่วางบนผัง

ผล: Rakete เห็นโต๊ะส้ม + คานแกนทรี, Moon 40 เป็นเครื่องยาวมีฝาส้มเป็นช่วง, Nova X4 เห็นโต๊ะ + คานเจาะ, Booster เห็นฝาส้มครึ่งบน, Aurora เป็นตู้ดำมีมือจับส้ม

## ข้อมูลที่แอปใช้จากโปรเจกต์ Model

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `src/machines/*.js` (คัดลอกจาก `machines/*.js`) | สร้างโมเดลจริง → แปลงเป็นก้อนตอนเปิด 3D ครั้งแรก |
| `src/machines/data.js` (= `data/machines.js` + บล็อก `options` ของ Rakete 3500A) | ชื่อ หมวด ขนาดตามโบรชัวร์ อุปกรณ์เสริม (ไม่ใช้ราคา/สเปกแล้ว) |
| `src/machines/sizes.json` (จาก `npm run sizes` = `scripts/bbox.mjs`) | ขนาดฐานและจุดกึ่งกลางของทุกรุ่น และของทุกชุดตัวเลือกเสริม (`options` key เช่น `infeed+outfeed`) |
| `public/photos/*.webp` (จาก `photos/` ผ่าน `scripts/photos.mjs`) + `src/model/photos.ts` | รูปเครื่องจริงในคลังและแผงรายละเอียด |

อุปกรณ์เสริม: `data.js` → `options[].flags` คือ flag ที่ส่งเข้า `MODELS[id](flags)` (`rakete-real.js` RAKETE_VARIANTS) ขนาดของแต่ละชุดวัดไว้ล่วงหน้าใน `sizes.json` แอปไม่วัดเอง

## ที่ขอให้ฝั่ง Model ทำต่อ

1. **ก้อนที่ "กล่องกว่านี้"**: ลดรายละเอียดอีกขั้นให้แต่ละรุ่นเหลือก้อนใหญ่ไม่กี่ก้อน (ฐาน โต๊ะ คาน ตู้ควบคุม ฝา) แต่ยังแยกรุ่นออก
   แนวทางที่ทำได้ในฝั่ง Model: เพิ่มโหมดใน `lowpoly.js` หรือฟังก์ชันใหม่ที่รับโมเดลแล้วคืน "ก้อน" โดยใช้กฎเดียวกับข้อ 3 ข้างบน
   แต่ปรับ `MIN_PART` ใหญ่ขึ้น (เช่น 0.25–0.4 ม.) และรวมชิ้นที่ติดกันสีเดียวกันเป็นกล่องเดียว ถ้าทำเป็น export เช่น `blockyMachine(machine, opts)` ฝั่งแอปจะเรียกใช้ได้ทันทีแทนตัวแปลงของตัวเอง
2. **หน้าเปรียบเทียบ** ในโปรเจกต์ Model: แต่ละรุ่นแสดง 4 ช่องเทียบกัน กล่องเปล่า (ขนาดจริง) → ก้อนเหลี่ยม → โมเดลเต็ม → รูปถ่ายจริง
   เพื่อให้พี่ต่อเลือกระดับที่รับได้ (น่าจะต่อยอดจาก `list.html` / `index.html?m=<id>` ที่มีอยู่)
3. ถ้าเปลี่ยนโมเดลหรือเพิ่มรุ่น: คัดลอก `machines/*.js` มาทับ `src/machines/` ในแอป คัดลอกรูปเข้า `photos/` แล้วรัน `node scripts/photos.mjs` และ `npm run sizes` (ดู README หัวข้อ "ขนาดเครื่อง Mastrox")

## ปรับได้ตรงไหน

- หยาบ/ละเอียด: `MIN_PART`, `MIN_TUBE` ใน `src/view3d/machines3d.ts` (ทดลอง 0.18 แล้วมือจับและไฟของ Aurora หาย จึงใช้ 0.12)
- สีชิ้นที่มี texture: `TEXTURED`
- ไม่มีโมเดล: แอปใช้กล่องเทาขนาดจริงมีขีดส้มด้านหน้า (`machineBlock` ใน `src/view3d/furniture3d.ts`)

## แก้ในแอปแล้ว ยังไม่ได้ใส่กลับโปรเจกต์ Model (23 ต.ค. 2026)

ถ้าคัดลอก `machines/*.js` ชุดใหม่จากโปรเจกต์ Model มาทับ ต้องใส่สามจุดนี้กลับ หรือให้ฝั่ง Model ใส่ไว้ที่ต้นทาง

1. **`rakete-real.js` ตู้คอนโทรล**: ตั้งขนานกับฐานเครื่องด้านหลัง ห่าง 30 ซม.
   `cabinet.position.set(-BL / 2 + 0.55, 0, -(BD / 2 + 0.28 + 0.3)); cabinet.rotation.y = 0;`
   (เดิม `(-2.62, 0, -1.3)` และหมุน 0.08) แก้แล้วต้องรัน `npm run sizes`
2. **`blocky.js` โลโก้**: `placeLogo` แปะโลโก้บนก้อนที่อยู่ใต้จุดกลางโลโก้ และใกล้โลโก้ที่สุดตามทิศที่มันหัน
   ไม่ใช่ก้อนที่อยู่หน้าสุด (เดิมโลโก้ตู้คอนโทรลไปลอยหน้าฐาน)
3. **`lib.js` URL ภาพโลโก้**: เขียน `new URL('../assets/mastrox-logo-thin.png', import.meta.url)` เต็มชื่อไฟล์ทั้งสองไฟล์
   (เดิมต่อชื่อไฟล์จากตัวแปร ทำให้ตอน build ภาพหาย) และ `paint()` ข้ามไปถ้าภาพโหลดไม่สำเร็จ
