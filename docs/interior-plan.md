# แผน: หน้าออกแบบภายใน (Interior) แยกจากตัวหลัก

เป้าหมาย: เพิ่ม "โปรเจกต์ชนิดตกแต่งภายใน" เป็นหน้าของตัวเอง ต่อยอดจากเครื่องมือเดิม (แปลน ผนัง ห้อง ประตู 3D แชร์)
โดย **ไม่เปลี่ยนพฤติกรรมของโปรเจกต์โรงงานเดิมแม้แต่จุดเดียว** ไฟล์ `.factory.json` เก่าเปิดได้เหมือนเดิม

หลักเดิมยังใช้: ไม่ใส่ข้อมูลที่แอปสมมติขึ้นเอง (ราคา สเปก) ไม่มีโหมดสมจริงเกินจำเป็น

## เฟส 1 รายละเอียด

### 1.1 โครง
- `Project.kind?: 'factory' | 'interior'` ใน `src/model/types.ts` ไม่มี = `factory` (ไฟล์เก่าทุกไฟล์)
- หน้ารายการโปรเจกต์ (`src/projects/ProjectList.tsx`): เพิ่มปุ่ม/การ์ด "ห้องตกแต่งภายใน (ใหม่)" ข้างผังเปล่า สร้างโปรเจกต์ `kind: 'interior'` และเปิดด้วย route เดิม `#/p/<id>` การ์ดโปรเจกต์ interior มีป้ายบอกชนิด
- `src/App.tsx`: ถ้า `project.kind === 'interior'` render `InteriorEditor` แทน `Editor` (จุดต่อแขวนจุดเดียว)
- โค้ดใหม่ทั้งหมดอยู่ใน `src/interior/` : `InteriorEditor.tsx`, `materials.ts`, `MoodBoard.tsx`, `interior3d.ts` ฯลฯ
- `InteriorEditor` ประกอบจาก `PlanEditor`, `View3D`, แถบเครื่องมือ, แผงขวา เดิม แต่:
  - เครื่องมือ: ผนัง ห้อง ประตู/หน้าต่าง วัด ภาพแปลน (ตัด เสา-ตารางเสา, ทางเดิน/โฟล์คลิฟท์, ลูกศรทิศทางงาน ออก)
  - คลัง: ซ่อนแท็บ Mastrox ไว้ก่อน เหลือ "อุปกรณ์" (เฉพาะกลุ่มสำนักงาน/อื่น ๆ ที่เป็นเฟอร์นิเจอร์ได้) และ "ของฉัน"
  - ตัวเลือกโซนห้อง: ใช้ชุดสำหรับบ้าน (นั่งเล่น นอน ครัว น้ำ ทำงาน ระเบียง ฯลฯ) แทนโซนโรงงาน แยกเป็น catalog ของ interior ไม่แก้ `ZoneKind` เดิมแบบที่ทำให้โรงงานเปลี่ยน
- แชร์ลิงก์/บันทึก/ส่งออกไฟล์ ใช้ของเดิมทั้งหมด ไม่ต้องแตะ

### 1.2 วัสดุบนผิว
- โมเดล: `Room.finish?: { floor?: MaterialId; wall?: MaterialId; ceiling?: MaterialId }` และ `Wall.finish?: MaterialId` (ต่อผนังทับค่าของห้องได้) field ใหม่เป็น optional ทั้งหมด โรงงานไม่ตั้งค่า = ทำงานเหมือนเดิม
- คลังวัสดุ `src/interior/materials.ts`: รายการวัสดุพื้นฐาน ~15–20 อย่าง แต่ละอย่างมี id, ชื่อไทย, หมวด (พื้น/ผนัง/ฝ้า/ไม้/หิน), รหัสสีหลัก, ภาพ texture ขนาดเล็ก (≤ 256px, เก็บใน `public/materials/`) ใช้ภาพที่**สร้างเองด้วยโค้ด** (ลายไม้ กระเบื้อง ปูน แบบ procedural เป็น PNG/SVG) หรือ CC0 เท่านั้น ห้ามหยิบภาพจากเว็บที่ไม่รู้สิทธิ์
- อัปโหลดวัสดุเอง: ผู้ใช้เลือกรูป → เก็บเป็น asset ใน IndexedDB แบบเดียวกับภาพแปลน (`src/model/photos.ts` / persist) ให้ id อ้างอิง ติดไปกับไฟล์ส่งออกและลิงก์แชร์ (ย่อเป็น WebP เหมือน renders)
- 3D: `building3d.ts` ตอนนี้ระบายสีด้วย vertex color แบบเดียว ให้เพิ่มเส้นทางที่ห้อง/ผนังที่มี finish ได้ mesh แยกพร้อม `MeshLambertMaterial` ที่มี texture map (`RepeatWrapping`, สเกลตามขนาดจริงของวัสดุ เช่น กระเบื้อง 600 มม.) ห้องที่ไม่มี finish ต้องเรนเดอร์ผ่านทางเดิมเป๊ะ (เทสต์ด้วยโปรเจกต์โรงงานตัวอย่างว่าภาพไม่เปลี่ยน)
- ฝ้า: interior เพิ่มแผ่นฝ้าที่ความสูงห้อง (โรงงานไม่มีฝ้า คงเดิม) มีปุ่มซ่อนฝ้าเพื่อมองจากบน
- UI: แผงขวา เมื่อเลือกห้อง มีส่วน "วัสดุ" สามแถว พื้น/ผนัง/ฝ้า คลิกเปิดตัวเลือกวัสดุเป็นกริดรูป มีปุ่มอัปโหลด; เลือกผนังเดี่ยวก็เลือกวัสดุของผนังนั้นได้
- 2D: พื้นห้องใน PlanEditor แสดงสีหลักของวัสดุพื้น (ไม่ต้องวาด texture บน canvas 2D)

### 1.3 Mood & Tone
- ปุ่ม "Mood & Tone" บนแถบบนของ InteriorEditor เปิดไดอะล็อก (ใช้ `src/ui/Dialog.tsx`)
- เนื้อหา สร้างจากโปรเจกต์ล้วน ๆ: ชุดสี (รหัส hex ของวัสดุทุกชิ้นที่ใช้ ไม่ซ้ำ), วัสดุที่ใช้ (รูป + ชื่อ + ใช้กับห้องไหน/พื้น-ผนัง-ฝ้า, พื้นที่รวม ตร.ม. ที่คิดจากเรขาคณิต), เฟอร์นิเจอร์ (ชื่อ จำนวน ขนาด ก×ย×ส จาก objects)
- ส่งออกเป็น PNG หน้าเดียว (ใช้แนวทางเดียวกับ `exportImage.ts` หรือ render เป็น canvas) ไม่ต้องทำ PDF ในเฟสนี้
- ไม่มีราคา ไม่มีข้อมูลที่แอปแต่งขึ้น
