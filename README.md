ออกแบบผังโรงงาน วางเครื่องจักร Mastrox แล้วจำลองพนักงานทำงานทั้งวัน (08:00–17:00) ในมุมมอง 2D / 3D แบบ low poly

## สองโหมด

**ออกแบบผัง** (ระบบสร้างผังจาก `D:\work\room`)
- ผนัง / ผนังกระจก, โซน (ห้องสี่เหลี่ยม, L, U, ตัดมุม), ประตู (รวมประตูม้วน), หน้าต่าง, ช่องเปิด
- **เสา**: เสาเหลี่ยม, เสากลม, หรือ *ตารางเสา* (ลากกรอบแล้ววางเสาทุกระยะที่ตั้ง ค่าเริ่มต้น 8 ม.)
- แต่ละโซนมีประเภท (ไลน์ผลิต, คลัง, สำนักงาน, โรงอาหาร, ห้องน้ำ, ซ่อมบำรุง, QC ฯลฯ) เป็นตัวบอกว่าคนจะไปทำอะไรที่นั่น
- คลังเครื่องจักร: เครื่อง Mastrox ทุกรุ่นที่มีโมเดล + อุปกรณ์ในโรงงาน (โต๊ะทำงาน, ชั้นวางพาเลท, โต๊ะช่าง, โต๊ะ QC, ล็อกเกอร์, เครื่องสแกนนิ้ว, ห้องสุขา, โต๊ะอาหาร ฯลฯ)
- **ภาพแปลน**: อัปโหลดรูป / PDF ของ layout แล้วกด "สร้างผนังจากแปลน" (หาสเกลจากประตูเอง หรือวัดเองด้วยการคลิก 2 จุด)
- แผงพนักงาน: เพิ่มคน กำหนดตำแหน่ง ที่ประจำ เวลาเข้า-ออก วันลา หรือ "สร้างทีมงานอัตโนมัติตามผัง"
- ตั้งเวลาเข้างาน เลิกงาน ช่วงพัก ลูกค้าต่อวัน อัตราเครื่องเสีย และเวลาซ่อม ได้ที่แผงขวา (คลิกที่ว่างบนแปลน)

**จำลองการทำงาน**
- พนักงานมาถึงก่อนเวลา สแกนนิ้ว เข้าล็อกเกอร์ ไปที่ประจำ พักตามตาราง ไปห้องน้ำ / ดื่มน้ำ แล้วเลิกงานออกทางเข้าหลัก
- ช่างคุมเครื่องเดินเครื่อง เครื่องเสียได้แบบสุ่ม → แจ้งซ่อม → ช่างซ่อมหยิบเครื่องมือแล้วไปซ่อม
- พนักงานคลังส่งวัตถุดิบ, QC สุ่มชิ้นงาน, หัวหน้างานเดินตรวจไลน์, ประชุมเช้า 08:30
- ลูกค้าเข้ามาแบบสุ่ม ติดต่อเคาน์เตอร์ รอที่โซฟา ฝ่ายขายมารับ พาชมโชว์รูม เครื่องจักร คุยในห้องประชุม แล้วส่งกลับ
- Tracking: คลิกคน (ในรายชื่อ, 2D หรือ 3D) เพื่อดูว่ากำลังทำอะไร อยู่ที่ไหน **ต่อไปจะไปทำอะไรที่ไหน** เส้นทางที่จะเดิน รอยที่เดินมา และสรุปทั้งวัน
- ไทม์ไลน์ทั้งวันของทุกคน, สถานะ/อัตราการใช้งานเครื่องจักร, รายการเหตุการณ์
- ปรับความเร็ว 1× – 300×, เลื่อนเวลา, "เริ่มวันใหม่" เพื่อสุ่มเหตุการณ์ใหม่

## 3D แบบ low poly

- อาคาร (พื้น ผนัง หน้าต่าง เสา) รวมเป็นไม่กี่ mesh, เฟอร์นิเจอร์เป็น geometry สีตาม vertex ชิ้นเดียว
- เครื่อง Mastrox สร้างจากโมเดลใน `src/machines` (คัดลอกจาก `D:\work\Mastrox Models\machines`) โดยลดส่วนโค้งเหลือ 8 ด้าน แล้วรวมทุกชิ้นเป็น geometry เดียวต่อรุ่น ใช้ซ้ำทุกเครื่อง
- ปุ่มมุมขวาบนของ 3D: ตัดผนังให้เตี้ย, **โหมดสมจริง**, เงา (ปิดไว้เพื่อความลื่น), ชื่อคน, เส้นทางเดินของทุกคน

### โหมดสมจริง

สลับได้จากปุ่มในมุมมอง 3D (จำค่าไว้ในเบราว์เซอร์) โดยไม่กระทบโหมด low poly เดิม:
- คนเป็นโมเดลละเอียด (`src/view3d/people3dReal.ts`): ลำตัว ไหล่ ข้อต่อ มือมีนิ้ว หน้าตา ผม แว่น หมวกนิรภัย เสื้อกั๊กสะท้อนแสง บัตรพนักงาน ตามตำแหน่งงาน สีผิว/ทรงผม/ส่วนสูงสุ่มคงที่จากรหัสพนักงาน
- วัสดุและแสง (`src/view3d/realistic.ts`): สลับ material เดิมเป็น PBR (พื้นคอนกรีตมีลายและรอยตัด ผนังมีเกรน กระจกใส), แสงจากสภาพแวดล้อม, เงานุ่ม, tone mapping และ ambient occlusion (GTAO) — หนักกว่าโหมดปกติ

ถ้าแก้โมเดลใน Mastrox Models ให้คัดลอกไฟล์ `machines/*.js` มาทับใน `src/machines/` (คงบรรทัด `LOW_SEG` / `lowSeg` ใน `lib.js` ไว้) แล้วรัน `npm run sizes` เพื่ออัปเดตขนาดฐานเครื่อง

## โครงสร้าง

```
src/model      ผัง (จาก room planner), เสา, โซน, ตำแหน่งงาน, คลังเครื่องจักร, โรงงานตัวอย่าง
src/editor2d   แปลน 2D และเครื่องมือวาด
src/sim        nav grid + A*, engine จำลองวันทำงาน
src/view3d     ฉาก three.js แบบ low poly
src/panels     แผงคุณสมบัติ คลัง พนักงาน และแผงจำลอง
src/machines   โมเดล Mastrox + ขนาด (sizes.json)
```

ข้อมูลโปรเจกต์บันทึกใน IndexedDB ของเบราว์เซอร์ และส่งออก/นำเข้าเป็นไฟล์ `.factory.json` ได้
