# แบบก่อสร้าง (src/drawings)

ชุดแบบ A3 แนวนอนจากโมเดลของโปรเจกต์ตกแต่งภายใน เปิดจากปุ่ม **แบบก่อสร้าง** บนแถบบน (มือถือ: เมนูหลัก)

```
types.ts            ชนิดข้อมูลกลาง Pt / Prim / Drawing (ใช้ร่วมกับ elevation/ ห้ามแก้)
sheets.ts           registry ของแผ่น (SHEET_DEFS), สร้างชุดแบบ + ปก, DXF ของแผ่น
sheet/geometry.ts   ความหนาเส้น เส้นประ มาตราส่วนมาตรฐาน รูปเส้นมิติ กรอบของหมึก
sheet/layout.ts     ขนาดแผ่น ขอบ กรอบชื่อแบบ พื้นที่วาด การวางวิวและเลือกมาตราส่วน
sheet/SheetSvg.tsx  วาดแผ่นเป็น SVG หน่วย มม.กระดาษ: กรอบ กรอบชื่อแบบ ปก วิว
plan/               แปลนพร้อมมิติ (planDrawing) และแผ่น ID-04-xx (planSheets)
dxf.ts              ตัวเขียน DXF R12 ASCII (และตัวอ่านง่าย ๆ สำหรับเทสต์)
DrawingsPage.tsx    หน้าดูชุดแบบ พิมพ์ ส่งออก DXF
```

## เพิ่มแผ่นใหม่

1. เขียนฟังก์ชันที่คืน `Drawing` (พิกัดโมเดล มม. y ขึ้น; ตัวหนังสือและระยะเส้นมิติเป็น มม.บนกระดาษ) ถ้าของบางอย่างต้องมีขนาดบนกระดาษ (วงกลมกริด) ให้รับมาตราส่วน `(scale) => Drawing` ได้
2. สร้าง `SheetDef` ที่คืนรายการ `SheetSpec` ต่อโปรเจกต์ เช่นรูปด้านหนึ่งแผ่นต่อผนัง:

```ts
export const elevationSheets: SheetDef = {
  key: 'elevation',
  sheets: (project) =>
    walls(project).map((w, i) => ({
      id: `ID-09-${String(i + 1).padStart(2, '0')}`,
      title: 'ELEVATION / รูปด้าน',
      views: [elevationDrawing(project, w)], // หลายวิวต่อแผ่นได้ จัดแถวให้เอง
      dxf: true, // ถ้าอยากให้ส่งออก DXF ได้
    })),
};
```

3. ใส่ไว้ใน `SHEET_DEFS` ใน `sheets.ts` ชุดแบบเรียงตามเลขแผ่น ปก (`ID-00-01`) สร้างสารบัญจากทุกแผ่นเอง แต่ละแผ่นได้มาตราส่วนเดียวกันทั้งแผ่น: ใหญ่ที่สุดใน 1:20 1:25 1:30 1:40 1:50 1:75 1:100 ที่ทุกวิวใส่พอดี (ใหญ่เกินก็ไล่ต่อ 1:150 … 1:1000)

## การอ่าน Prim ของตัววาดแผ่น

- `text.rotate` เป็นเรเดียนทวนเข็มนาฬิกา, `text.at` คือเส้นฐาน, `anchor` แนวนอน (ค่าเริ่มต้น `start`)
- `poly.fill: 'poche'` ดำทึบ (#1a1a1a) สตริงอื่นเป็นสี CSS
- `dim` เส้นมิติอยู่ `offset` มม.กระดาษทางซ้ายของ a→b เส้นช่วยห่างจุด 1.5 มม. เลยเส้นมิติ 1.5 มม. ขีดเฉียง 45° ตัวเลขอยู่เหนือเส้น (หน่วยตามที่เลือก: มม. เต็ม, ซม. ทศนิยม 1 ตำแหน่งเมื่อมี, ม. ทศนิยม 2 ตำแหน่ง หรือ 3 ถ้าเศษ มม. จะหาย; ปัดเป็น มม. เต็มก่อนเสมอ `fmtLength`) อ่านจากล่างหรือขวา ถ้าช่วงสั้นกว่าตัวเลข ตัวเลขย้ายไปเลยปลาย b
- เส้นประ (มม.กระดาษ): dashed 3/1.5, hidden 1.5/1, center 6/1.5/1/1.5 · ความหนา thin 0.13 medium 0.25 thick 0.35 cut 0.5

## แปลนพร้อมมิติ

ผนังเป็นรูปตัดจาก `wallFootprints` ตัดช่วงช่องเปิดออก สัญลักษณ์ประตู/หน้าต่างมาจาก `openingSymbol` ตัวเดียวกับแปลนบนจอ แถวมิติด้านนอกแต่ละด้าน (ในออกนอก ห่าง 8 มม.): ช่องเปิดบนผนังนอกที่หันด้านนั้น → ผิวนอกถึงแนวศูนย์กลางผนังนอกและผนังกั้นที่อยู่ครึ่งด้านนั้น → มิติรวมผิวนอก (เฉพาะด้านล่างและขวา) แถวเริ่มเลยของที่ยื่นออกนอกผนัง (บานเปิดออก บานเลื่อน) กริดอยู่ที่แนวศูนย์กลางผนังนอกที่ตั้งฉากแกน เลข 1,2,… ซ้ายไปขวา อักษร A,B,… ล่างขึ้นบน (ข้าม I, O) พื้นที่ห้องวัดถึงแนวศูนย์กลางผนังเหมือนทั้งแอป

## พิมพ์และ DXF

พิมพ์ใช้ `@page drawings-a3` และคลาส `drawings-printing` บน `<html>` ระหว่างที่หน้านี้เปิด หน้ามี `@page` ค่าเริ่มต้นเป็น A3 แนวนอนด้วย เพราะ Chrome จัดหน้ากว้างตามหน้าค่าเริ่มต้น (A4 ของ BOQ) แล้วย่อแผ่นลง ~67%

DXF R12 หน่วย มม. ขนาดจริง layer ตามชื่อ layer ของ Prim, poche เป็น SOLID สามเหลี่ยมใน layer เดียวกัน, เส้นมิติแตกเป็นเส้นกับ TEXT, ตัวอักษรไทยเป็น `\U+XXXX`, ขนาดตัวหนังสือ = มม.กระดาษ × มาตราส่วนของแผ่น

## หน่วย

ปุ่มเฟือง (ตั้งค่าแบบ) บนแถบของหน้าแบบก่อสร้าง มีตัวเลือกหน่วย **มม. / ซม. / ม.** เปลี่ยนเฉพาะตัวเลขมิติ (บนแผ่น ในไฟล์ PDF และในข้อความ DXF) และหมายเหตุในกรอบชื่อแบบ ("หน่วย ซม. · ตรวจระยะหน้างาน") เส้น มาตราส่วน และพิกัด DXF ยังเป็น มม. ขนาดจริงเสมอ พื้นที่ห้องเป็น ตร.ม. ทุกหน่วย ค่าที่เลือกจำไว้ในเบราว์เซอร์ (`localStorage` คีย์ `drawings-unit`) ไม่ได้เก็บกับโปรเจกต์
